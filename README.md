# ربات آزمون گروهی اوتیسما

## نصب

```bash
pip install -r requirements.txt
```

> تایمر سوال‌ها به `python-telegram-bot[job-queue]` نیاز داره (توی `requirements.txt` هست).
> اگه از نسخه‌ی قبلی آپدیت می‌کنی، یه بار دوباره همین دستور رو بزن. دیتابیس قدیمی خودکار آپدیت میشه و آزمون‌های قبلی سالم می‌مونن.

## تنظیمات (متغیرهای محیطی)

```bash
export BOT_TOKEN="توکن ربات از BotFather"
export OWNER_ID="آی‌دی عددی خودت"   # مثلاً 123456789
```

تنظیمات اختیاری (پیش‌فرض‌ها توی پرانتزن):

```bash
export QUESTION_TIME_LIMIT=120   # مهلت هر سوال به ثانیه (۱۲۰ = ۲ دقیقه)
export MAX_POINTS=1000           # امتیاز جواب درستِ فوری (۱۰۰۰)
export MIN_POINTS=100            # امتیاز جواب درست در آخرین لحظه‌ی مهلت (۱۰۰)
export RICH_RESULTS=1            # نتیجه‌ی Rich با جدول (۱) یا متن ساده (۰)
```

> با `/testrich` (در چت خصوصی، ادمین) می‌تونی تست کنی `sendRichMessage` روی سرور/کلاینتت کار می‌کنه یا نه؛ اگه نه، نتیجه خودکار متن ساده میشه.

آی‌دی عددی خودت رو می‌تونی از رباتی مثل @userinfobot بگیری.

## اجرا

```bash
python3 main.py
```

## نکات مهم قبل از اجرا

1. توی BotFather برای ربات، **Inline Mode** رو فعال کن:
   `/setinline` روی ربات → یک متن placeholder بفرست (مثلاً "جستجوی آزمون...").
2. ربات رو به گروه اضافه کن و بهش دسترسی بده که پیام حذف/ویرایش کنه (کافیه عضو عادی گروه باشه چون فقط پیام‌های خودش رو ادیت می‌کنه، ولی بهتره ادمین گروه هم باشه).
3. Privacy Mode ربات (توی BotFather → Bot Settings → Group Privacy) بهتره **Disabled** باشه تا در گروه پیام‌های معمولی رو هم ببینه (برای این ربات ضروری نیست چون فقط از دکمه و inline استفاده می‌کنیم، ولی برای اطمینان خاموشش کن).

## نحوه کار

### ۱. ساخت آزمون (فقط در چت خصوصی با ربات)
- `/panel` رو بزن.
- «➕ ساخت آزمون جدید» → اسم آزمون، بعد سوال‌ها و گزینه‌ها رو یکی‌یکی بفرست.
- تعداد سوال و گزینه نامحدوده. بعد از هر سوال جواب درست رو انتخاب کن.
- در آخر «✅ پایان و ذخیره آزمون» رو بزن.
- 💡 برای آزمون تکراری، از صفحه آزمون «📋 کپی آزمون» رو بزن و بعد ویرایشش کن (سریع‌ترین راه ساخت آزمون جدید).

### ۲. ویرایش آزمون (فقط در چت خصوصی با ربات)
- از پنل → «📋 لیست آزمون‌ها» → آزمون → «✏️ ویرایش آزمون».
- می‌تونی اسم آزمون، متن سوال، متن گزینه‌ها و جواب درست رو عوض کنی، سوال حذف یا اضافه کنی.
- ویرایش وقتی آزمون در حال اجراست (ثبت‌نام/در حال برگزاری) بلاکه تا نتیجه خراب نشه.

### ۳. مدیریت ادمین‌ها (فقط سازنده اصلی = OWNER_ID)
- از پنل → «👥 مدیریت ادمین‌ها»، یا دستور سریع:
  `/addadmin <آیدی عددی>`

### ۳. اجرای آزمون در گروه
- داخل گروه بنویس `@نام_ربات` و اسم آزمون رو جستجو کن (Inline Mode).
- آزمون مورد نظر رو انتخاب کن تا پیامش با دکمه «🚀 شروع آزمون» توی گروه بیاد.
- روی «شروع آزمون» بزن → مرحله‌ی ثبت‌نام شروع میشه؛ اعضا دکمه‌ی «🙋 من یک اوتیسمی پایه هستم» رو می‌زنن.
- وقتی همه ثبت‌نام کردن، ادمین/سازنده دکمه‌ی «▶️ شروع آزمون» رو می‌زنه.
- هر سوال با جدول و دکمه‌ها نمایش داده میشه (Rich)؛ جواب دادن سایلنته و هیچ پاپ‌آپی روی صفحه نمیاد؛ انتخابت به بقیه نشون داده نمیشه.
- **تایمر:** هر سوال ۲ دقیقه مهلت داره. وقتی همه جواب بدن یا مهلت تموم بشه، خودکار میره سوال بعد. ادمین/سازنده هر موقع خواست می‌تونه با «⏭ سوال بعدی» سوال رو زودتر رد کنه.
- **امتیاز:** جواب غلط یا بی‌جواب = ۰. جواب درست بین ۱۰۰ تا ۱۰۰۰ امتیاز داره و هرچی سریع‌تر باشه امتیازش بیشتره (کاهش خطی با زمان). توی جواب‌دادن، ربات به خود شخص می‌گه چند ثانیه طول کشید، ولی درست/غلط بودن تا آخر مخفی می‌مونه. تساوی امتیاز: اول جواب‌درست بیشتر، بعد زمان کمتر.
- بعد از آخرین سوال، نتیجه به‌صورت مرتب نمایش داده میشه: رتبه‌بندی نهایی (بر اساس امتیاز) + درصد هر گزینه برای هر سوال (بدون اسم کسایی که هر گزینه رو زدن).
- اگه ربات وسط آزمون ری‌استارت بشه، تایمر آزمون‌های در حال اجرا خودکار برمی‌گرده.

## دیتابیس

از SQLite استفاده شده (فایل `autisma.db`، قابل تغییر با `DB_PATH`). برای استفاده‌ی واقعی و مداوم بهتره ربات روی یک سرور (VPS) به‌صورت دائم (مثلاً با systemd یا screen/tmux) اجرا بشه.
