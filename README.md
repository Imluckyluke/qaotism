# ربات آزمون گروهی اوتیسما

## نصب

```bash
pip install -r requirements.txt
```

## تنظیمات (متغیرهای محیطی)

```bash
export BOT_TOKEN="توکن ربات از BotFather"
export OWNER_ID="آی‌دی عددی خودت"   # مثلاً 123456789
```

آی‌دی عددی خودت رو می‌تونی از رباتی مثل @userinfobot بگیری.

## اجرا

```bash
python3 main.py
```

## نکات مهم قبل از اجرا

1. توی BotFather برای ربات، **Inline Mode** رو فعال کن:
   `/setinline` روی ربات → یک متن placeholder بفرست (مثلاً "جستجوی آزمون...").
2. ربات رو به گروه اضافه کن و بهش دسترسی بده که پیام حذف/ویرایش کنه (کافیه عضو عادی گروه باشه چون فقط پیام‌های خودش رو ادیت می‌کنه، ولی بهتره ادمین گروه هم باشه).
3. Privacy Mode ربات (توی BotFather → Bot Settings → Group Privacy) بهتره **Disabled** باشه تا در گروه پیام‌های معمولی رو هم ببینه (برای این ربات ضروری نیست چون فقط از دکمه و inline استفاده می‌کنیم، ولی برای اطمینان خاموشش کن).

## نحوه کار

### ۱. ساخت آزمون (فقط در چت خصوصی با ربات)
- `/panel` رو بزن.
- «➕ ساخت آزمون جدید» → اسم آزمون، بعد سوال‌ها و گزینه‌ها رو یکی‌یکی بفرست.
- تعداد سوال و گزینه نامحدوده. بعد از هر سوال جواب درست رو انتخاب کن.
- در آخر «✅ پایان و ذخیره آزمون» رو بزن.

### ۲. مدیریت ادمین‌ها (فقط سازنده اصلی = OWNER_ID)
- از پنل → «👥 مدیریت ادمین‌ها»، یا دستور سریع:
  `/addadmin <آیدی عددی>`

### ۳. اجرای آزمون در گروه
- داخل گروه بنویس `@نام_ربات` و اسم آزمون رو جستجو کن (Inline Mode).
- آزمون مورد نظر رو انتخاب کن تا پیامش با دکمه «🚀 شروع آزمون» توی گروه بیاد.
- روی «شروع آزمون» بزن → مرحله‌ی ثبت‌نام شروع میشه؛ اعضا دکمه‌ی «🙋 من هستم» رو می‌زنن.
- وقتی همه ثبت‌نام کردن، ادمین/سازنده دکمه‌ی «▶️ شروع آزمون» رو می‌زنه.
- هر سوال با دکمه‌های شیشه‌ای نمایش داده میشه؛ هرکس جواب بده به بقیه نشون داده نمیشه.
- وقتی همه جواب بدن، خودکار میره سوال بعد. اگه یکی جواب نده، ادمین/سازنده می‌تونه «⏭ سوال بعدی» رو بزنه.
- بعد از آخرین سوال، نتیجه‌ی کامل (جواب درست، درصد هر گزینه، اسم کسایی که هر گزینه رو زدن) نمایش داده میشه.

## دیتابیس

از SQLite استفاده شده (فایل `autisma.db`، قابل تغییر با `DB_PATH`). برای استفاده‌ی واقعی و مداوم بهتره ربات روی یک سرور (VPS) به‌صورت دائم (مثلاً با systemd یا screen/tmux) اجرا بشه.
